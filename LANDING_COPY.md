# FAQ

## What tools does SpendScope support?

SpendScope currently supports:
- ChatGPT
- Claude
- Cursor
- GitHub Copilot
- Gemini
- OpenAI API
- Anthropic API
- Midjourney
- Jasper
- Grammarly
- Notion AI
- Windsurf

with extensible support for additional AI tooling.

---

## Does SpendScope connect to my accounts?

No.

The MVP intentionally avoids direct billing integrations.

Users manually enter:
- tools
- plans
- spend
- team size
- use cases

This reduces friction and allows instant audits without OAuth or sensitive permissions.

---

## How accurate are the recommendations?

Savings calculations are deterministic and rule-based.

Recommendations are generated using:
- current vendor pricing
- seat counts
- usage-fit reasoning
- cross-tool overlap detection

LLMs are used only for:
- semantic interpretation
- recommendation wording
- summary generation

not financial calculations.

---

## Why does SpendScope sometimes say “You’re spending well”?

The goal is not to manufacture savings.

If a stack appears appropriately optimised relative to the team’s use case, SpendScope explicitly communicates that instead of forcing unnecessary recommendations.

---

## Is my data public?

No identifying information is exposed publicly.

Public share URLs intentionally strip:
- email addresses
- company names
- personal identifiers

Only:
- tools
- recommendations
- savings summaries

are shown in shared reports.
