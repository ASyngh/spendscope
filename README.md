# SpendScope

SpendScope is an AI spend audit platform that helps startups analyze and optimize their spending on AI tools like ChatGPT, Claude, Gemini, Cursor, GitHub Copilot, and other AI productivity software.

The platform audits tool usage, detects overlapping subscriptions, identifies unnecessary costs, recommends cheaper plans or alternatives, and estimates potential monthly and yearly savings through a clean, modern web experience.
